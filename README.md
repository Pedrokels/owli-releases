# Owli: downloads

Owli is a teacher's helper for class lists, attendance, class records,
reminders and more. It runs on Android and keeps your data on your phone.

Owli is in **beta**. You need the activation code you received from the Owli
team.

## Download

- **[owli-arm64.apk](https://github.com/Pedrokels/owli-releases/releases/latest/download/owli-arm64.apk)**: most phones
- **[owli-older-phones.apk](https://github.com/Pedrokels/owli-releases/releases/latest/download/owli-older-phones.apk)**: only if the first one won't install

All versions: [Releases](https://github.com/Pedrokels/owli-releases/releases)

## Install

1. Open the downloaded file.
2. If Android asks, allow installing apps from that source (for example, your
   browser or Files). If Google Play Protect warns about an unknown app,
   choose to install anyway. Owli isn't on the Play Store yet.
3. Open Owli, finish the short setup, then enter your activation code. You
   need internet once for this; after that, Owli works offline.

## Updates

Owli tells you when there's a new version (**Settings → About → Check for
updates**). Updating keeps all your classes and records.

**Don't uninstall Owli.** Uninstalling deletes your data on the phone. Make a
backup first (**Settings → Backup & restore**) if you ever need to.

---

This repository only holds the app downloads (`manifest.json` tells Owli about
the newest version). It contains no source code and no personal data.
